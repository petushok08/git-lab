# git-lab

Лабораторная работа «Git: от локального репозитория до Pull Request» по курсу «Введение в специальность».

## Что сделано

| № | Задание | Где посмотреть |
|---|---------|----------------|
| 1–3 | Локальный репозиторий, состояния файлов, объекты Git | первые коммиты истории |
| 4 | Ветки: обычный merge и squash | `feature/ordinary`, `feature/squash` |
| 5 | Связь с GitHub, синхронизация двух копий | — |
| 6 | Шаблон PR, CI, защита `main` | [`.github/`](.github), [PR #1](../../pull/1) |
| 7 | Issue, PR и разрешение конфликта | [Issue #4](../../issues/4), [PR #5](../../pull/5) |
| 8 | Code Review | [PR #8](../../pull/8) |
| 9–10 | Поиск секретов TruffleHog: падение и починка CI | [Issue #9](../../issues/9), [PR #10](../../pull/10) |

## Файлы

- `binary_search.py` — функция бинарного поиска (задание 8)
- `notes.txt`, `data.txt`, `secret.txt` — файлы для проверки состояний и `.gitignore` (задание 2)
- `ordinary.txt`, `squash.txt` — изменения из веток задания 4
- `.github/pull_request_template.md` — шаблон Pull Request
- `.github/workflows/ci.yml` — CI: проверка репозитория и поиск секретов (TruffleHog)

## Правила работы

Ветка `main` защищена: изменения попадают в неё только через Pull Request и только после успешной проверки CI.
